# Fabao Bot — консультант по подбору тоника

Telegram-бот, который помогает подобрать тоник для волос 101G, 101B или 101 Formula на основе ответов на вопросы.

## Задача бота

Клиенты Fabao часто не знают, какой тоник им подходит. Бот задаёт 5–6 вопросов о типе выпадения, наследственности, жирности кожи головы и других факторах, а затем рекомендует наиболее подходящий продукт.

## Как работает бот

1. Пользователь запускает бота и нажимает "Начать тест".
2. Бот задаёт вопросы и запоминает ответы.
3. Каждый ответ добавляет баллы к одному из трёх тоников.
4. В конце бот отправляет картинку с подходящим тоником и кнопкой "Перейти на сайт".

## Техническая реализация

- Язык: Python 3.14
- Библиотека: pyTelegramBotAPI (telebot)
- Хранение данных: clonar `user_data` (в будущем можно заменить на SQLite)
- Кнопки: InlineKeyboardMarkup
- **Картинки: отправляются из папки `photo_results/`
